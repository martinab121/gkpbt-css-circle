# CSS Circle

A small HTML and CSS exercise that draws a blue circle from a plain `div` using `border-radius: 50%`.

## How it works

- `circle.html` contains a `div` with the classes `blue` and `circle`
- `style.css` gives the `div` a fixed 300 × 300 px size, a blue background and `border-radius: 50%`, which turns the square into a circle

## Tech stack

| Area | Technologies |
|---|---|
| Markup | HTML |
| Styling | CSS |

## Project structure

```
circle.html   page with the circle element
style.css     circle styles
```

## Getting started

Open `circle.html` in any web browser. No build step is needed.
